# Sistema de Gestão de Coletas — Associação Sol Nascente

Protótipo inicial em HTML, CSS e JavaScript puro.

## Arquivos
- `index.html` — estrutura das telas
- `style.css` — identidade visual e responsividade
- `app.js` — cadastro, armazenamento local, filtros, status e pré-roteirização
- `logo-sol-nascente.png` — logo fornecida

## Como testar
Abra `index.html` no navegador.
